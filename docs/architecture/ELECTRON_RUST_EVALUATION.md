# Electron waveform experiment

Core `147a2cfa656e254f2dea792c3c67cc47bf5dcad8` runs as a child process for the detailed waveform IPC. It has its own timeout and returns a bounded versioned JSON payload. Main checks the schema, rate, band sizes and finite ranges. This gives a process boundary for decode and waveform work and is straightforward to package and profile. N-API could eliminate process startup and JSON serialization, with native code sharing the Electron process and a separate per-target binary compatibility matrix. Benchmark it only after a relevant profile exposes this boundary as a meaningful cost.

The original UI, analyzer, cache and all exports are used. Select `CUEKODA_WAVEFORM_ENGINE=legacy` or `rust` before launch. An experimental dev run uses its own analytics cache and preferences under the CueKoda Waveform Experiment user-data directory. A debug Rust selection requires an absolute `CUEKODA_RUST_CORE` path; the packaged experiment defaults to its bundled executable. It has a distinct app ID, product name and installer, and the production updater is disabled in this variant.

```sh
npm ci
cargo build --release --locked --manifest-path rust/cuekoda-core/Cargo.toml
CUEKODA_WAVEFORM_ENGINE=rust CUEKODA_RUST_CORE="$PWD/rust/cuekoda-core/target/release/cuekoda-core" npm start
node scripts/benchmark-waveforms.mjs "$PWD/rust/cuekoda-core/target/release/cuekoda-core" /tmp/waveforms.json /path/to/synthetic.wav
```

This development-machine waveform IPC backend comparison used 10 alternating repetitions per input and the same FFmpeg executable. The fixture includes synthetic click tracks generated by `npm run offset-test`. The high WAV P95 shows interference or startup variability on this host. The measurement includes decoder and child-process JSON transport and does not cover a renderer frame or musical analysis. [Raw data](../benchmarks/raw/waveform-pair-macos-arm64.json)

The isolated arm64 DMG is 238,754,206 bytes. Inspection verified the distinct identifier, bundled Rust executable and FFmpeg, exclusion of Rust compiler output from ASAR, and ad hoc signature. The initial packaging experiment that included compiler outputs was 364,772,777 bytes. The rebuilt bundle used about 691,896 KiB on disk. The bundled macOS smoke completed analysis and cache reuse for four synthetic input files, with zero renderer errors. This analysis smoke exercises the legacy analyzer and UI; the paired waveform test directly exercises the Rust waveform integration. No CPU/peak memory advantage or full-engine speedup has been established.
